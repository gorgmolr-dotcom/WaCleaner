# WaCleaner — أداة شخصية لحذف الأرقام التي ليست على واتساب

أداة أندرويد بسيطة: تفحص جهات اتصال هاتفك، تكتشف أي رقم **ليس له واتساب**،
وتحذفه من دفتر الهاتف. وبما أن واتساب يعرض نفس دفتر الهاتف، تختفي هذه الأرقام من واتساب تلقائياً.
لا تفتح واتساب ولا تتلاعب به — تعمل فقط عبر واجهة أندرويد الرسمية للـ Contacts.

## بناء الـ APK أونلاين (بدون أي برنامج على جهازك)

1. اعمل حساب مجاني على github.com.
2. اعمل repository جديد (مثلاً WaCleaner) — Public.
3. ارفع كل ملفات هذا المجلد داخله (Add file → Upload files).
4. افتح تبويب **Actions** في المستودع — سيبدأ البناء تلقائياً (أو اضغط Run workflow).
5. بعد دقيقتين تقريباً، افتح آخر build → حمّل **WaCleaner-apk** من قسم Artifacts.
6. فك الضغط → انقل `app-debug.apk` لهاتفك → ثبّته (فعّل "تثبيت من مصادر غير معروفة").

## تنبيه مهم
الحذف نهائي. **خذ نسخة احتياطية لجهات اتصالك قبل الاستخدام**، واستخدم زر "فحص" أولاً
للتأكد من العدد قبل الحذف.
